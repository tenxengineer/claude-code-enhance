# claude-code-enhance

> [Claude Code](https://claude.com/claude-code) 用のプロンプトエンハンサー + 教訓ライブラリ + プロジェクトコードマップ。無料、ローカル動作、MIT ライセンス。

[English](../../README.md) · [简体中文](README.zh-CN.md) · **日本語** · [한국어](README.ko.md) · [Русский](README.ru.md)

![demo](../../assets/demo.svg)

3 つのスキルが協力して、AI コーディングエージェントを「ちょうど入ってきた賢いコンサルタント」ではなく「18 ヶ月コードベースに関わってきた優れたエンジニア」のように振る舞わせます。

## 何が得られるか

| スキル                      | 何をするか                                                                                                                     | いつ起動するか                                                                                                  |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| `/enhance <ラフなアイデア>` | コードベースのコンテキストを読み込み、プロンプトエンジニアリング原則を適用し、構造化されたプロンプトを生成。レビュー/編集/送信 | ユーザー制御(自分で入力)                                                                                        |
| `consult-scars`             | アーキテクチャ計画を作成する前に、教訓ライブラリから関連する教訓を読み込む                                                     | 自動起動(`design`、`refactor`、`migrate`、`add caching`、`auth` などのアーキテクチャ動詞を含むプロンプトで起動) |
| `/refresh-codemap`          | git 履歴から `hotfiles.md` と `recent.md` を再生成                                                                             | ユーザー制御(週次または大きな作業の前に実行)                                                                    |

加えて、スキルが存在する場合に使用し、存在しない場合は優雅に劣化するオプションのインフラストラクチャ(教訓ライブラリ、コードマップ、SessionStart フック)。

## なぜこれが必要か

既存の代替手段にはソロ開発者や小規模チームにとって実際の欠点があります:

|                                  | claude-code-enhance                     | Augment Code                             | claude-mem                             |
| -------------------------------- | --------------------------------------- | ---------------------------------------- | -------------------------------------- |
| **ライセンス**                   | MIT                                     | プロプライエタリ                         | AGPL-3.0(商用には毒)                   |
| **コスト**                       | $0(既存の Claude Code セッションを使用) | クエリごとにクレジット、不透明な価格設定 | 圧縮のための API トークン              |
| **プライバシー**                 | すべてローカル、マシンから離れない      | オプションのクラウドモード               | ローカル SQLite + Chroma               |
| **ロックイン**                   | なし — 自由に fork 可能                 | Augment インフラ                         | AGPL ウイルス的コピーレフト            |
| **コードベース認識**             | はい(codemap + Serena + grep)           | はい                                     | 間接的(圧縮サマリー)                   |
| **過去の教訓を相互参照**         | はい(組み込みの教訓ライブラリ)          | いいえ                                   | いいえ(代わりにすべてを自動キャプチャ) |
| **強化されたプロンプトの可視性** | はい(レビュー/編集/破棄)                | はい(Ctrl+P → バッファ置換)              | 該当なし(異なるツール)                 |
| **信頼モデル**                   | 監査可能なプレーン markdown             | ブラックボックスサービス                 | AI 圧縮されたサマリー                  |

哲学: **キュレーション > キャプチャ**。記憶の質は量よりもはるかに重要です。シニアエンジニアのノートブックは薄く権威的です。ジュニアのノートブックはあふれていて信頼できません。このプラグインは薄いノートブックです。

## クイックスタート

### オプション 1 — プラグインマーケットプレイス(公開後推奨)

```bash
# Claude Code 内で:
/plugin marketplace add tenxengineer/claude-code-enhance
/plugin install claude-code-enhance
```

### オプション 2 — 手動インストール

```bash
git clone https://github.com/tenxengineer/claude-code-enhance.git
cd claude-code-enhance

mkdir -p ~/.claude/skills
cp -r skills/enhance        ~/.claude/skills/
cp -r skills/consult-scars  ~/.claude/skills/
cp -r skills/refresh-codemap ~/.claude/skills/

# Claude Code を再起動 — スキルが /skills リストに表示されます
```

### オプション 3 — オプションインフラを含む完全インストール

```bash
bash scripts/bootstrap.sh
```

bootstrap スクリプトは冪等です — 再実行は安全です。

## 使用方法

### あいまいなプロンプトを強化

```
/enhance フィールド面積が誤って計算されるバグを修正
```

エージェントはコードベースのコンテキスト(あなたの `.codemap/`、あなたの `~/.claude/lessons/`、プロジェクトの `CLAUDE.md`、存在する場合は Serena MCP、最近の git アクティビティ)を読み込み、プロンプトエンジニアリング原則を適用し、構造化された強化プロンプトを表示します。あなたは:

- **送信** (`s`) — 強化バージョンを実際の指示として続行
- **編集** (`e`) — 送信前に修正
- **破棄** (`x`) — 元のラフな意図にフォールバック
