# claude-code-enhance

> Усилитель промптов + библиотека уроков + карта проекта для [Claude Code](https://claude.com/claude-code). Бесплатно, локально, лицензия MIT.

[English](../../README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · **Русский**

![demo](../../assets/demo.svg)

Три скилла, работающих вместе, чтобы ваш AI-агент кодинга вёл себя как опытный инженер, который работал над вашей кодовой базой 18 месяцев — а не как умный консультант, который только что вошёл.

## Что вы получаете

| Скилл                      | Что делает                                                                                                                                   | Когда срабатывает                                                                                                               |
| -------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `/enhance <черновая идея>` | Загружает контекст кодовой базы, применяет принципы prompt engineering, выдаёт структурированный промпт для проверки/редактирования/отправки | Управляется пользователем (вы вводите его)                                                                                      |
| `consult-scars`            | Загружает релевантные уроки из библиотеки шрамов перед составлением архитектурных планов                                                     | Автоматически срабатывает на промпты с архитектурными глаголами (`design`, `refactor`, `migrate`, `add caching`, `auth` и т.д.) |
| `/refresh-codemap`         | Регенерирует `hotfiles.md` и `recent.md` из истории git                                                                                      | Управляется пользователем (запускайте еженедельно или перед крупной работой)                                                    |

Плюс опциональная инфраструктура (библиотека уроков, codemap, SessionStart-хуки), которую скиллы используют, когда она есть, и без которой плавно деградируют.

## Зачем это нужно

Существующие альтернативы имеют реальные недостатки для соло-разработчиков и малых команд:

|                                          | claude-code-enhance                             | Augment Code                                    | claude-mem                                       |
| ---------------------------------------- | ----------------------------------------------- | ----------------------------------------------- | ------------------------------------------------ |
| **Лицензия**                             | MIT                                             | Проприетарная                                   | AGPL-3.0 (яд для коммерции)                      |
| **Стоимость**                            | $0 (использует существующую сессию Claude Code) | Кредиты за запрос, непрозрачное ценообразование | API-токены за компрессию                         |
| **Приватность**                          | Всё локально, никогда не покидает машину        | Опциональный облачный режим                     | Локальные SQLite + Chroma                        |
| **Привязка**                             | Никакой — форкайте свободно                     | Инфраструктура Augment                          | AGPL вирусный copyleft                           |
| **Понимание кодовой базы**               | Да (codemap + Serena + grep)                    | Да                                              | Косвенно (сжатые саммари)                        |
| **Перекрёстные ссылки на прошлые уроки** | Да (встроенная библиотека уроков)               | Нет                                             | Нет (вместо этого автоматически захватывает всё) |
| **Видимый улучшенный промпт**            | Да (вы проверяете/редактируете/отбрасываете)    | Да (Ctrl+P → замена буфера)                     | Не применимо (другой инструмент)                 |
| **Модель доверия**                       | Простой markdown, который можно проверить       | Чёрный ящик-сервис                              | AI-сжатые саммари                                |

Философия: **курация > захват**. Качество памяти бесконечно важнее количества. Блокнот сеньора тонкий и авторитетный; блокнот джуна переполнен и ненадёжен. Этот плагин — тонкий блокнот.

## Быстрый старт

### Вариант 1 — маркетплейс плагинов (рекомендуется после публикации)

```bash
# В Claude Code:
/plugin marketplace add tenxengineer/claude-code-enhance
/plugin install claude-code-enhance
```

### Вариант 2 — ручная установка

```bash
git clone https://github.com/tenxengineer/claude-code-enhance.git
cd claude-code-enhance

mkdir -p ~/.claude/skills
cp -r skills/enhance        ~/.claude/skills/
cp -r skills/consult-scars  ~/.claude/skills/
cp -r skills/refresh-codemap ~/.claude/skills/

# Перезапустите Claude Code — скиллы появятся в списке /skills
```

### Вариант 3 — полная установка с опциональной инфраструктурой

```bash
bash scripts/bootstrap.sh
```

Bootstrap-скрипт идемпотентен — повторный запуск безопасен.

## Использование

### Улучшение расплывчатого промпта

```
/enhance исправь баг где площадь поля считается неправильно
```

Агент загружает контекст кодовой базы (ваш `.codemap/`, ваш `~/.claude/lessons/`, проектный `CLAUDE.md`, Serena MCP, если установлен, недавнюю git-активность), применяет принципы prompt engineering и показывает структурированный улучшенный промпт. Вы можете:

- **Отправить** (`s`) — продолжить с улучшенной версией как фактической инструкцией
- **Редактировать** (`e`) — внести правки перед отправкой
- **Отбросить** (`x`) — вернуться к исходной черновой идее
